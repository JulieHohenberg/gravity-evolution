# Reinforcement learning

Reinforcement learning trains a controller through practice. The robot takes actions, receives a reward from the simulation, and uses that feedback to improve its decisions.

[Stable-Baselines3](https://github.com/DLR-RM/stable-baselines3) provides Proximal Policy Optimization (PPO), a reinforcement learning method that updates a controller using rewards from its attempts. PPO can be compared with the genetic algorithm under the same gravity and terrain settings.
